# MediCore 개발 규칙

> AI 도구(Claude Code, Cursor, Gemini 등)를 사용할 때 이 문서를 컨텍스트로 제공하세요.
> 팀원 전원이 반드시 숙지해야 합니다.

## 내가 작업할 폴더

각자 본인 이니셜 폴더 안에서만 작업합니다.

```
frontend/src/[이니셜]/      ← 프론트 페이지
backend-main/src/.../[이니셜]/   ← 백엔드 API
AI/[이니셜]/                ← AI 모델 코드
```

예) WJ라면:
```
frontend/src/WJ/BrainTumorPage.jsx   ← 이 파일만 수정
backend-main/.../WJ/                 ← 여기에 컨트롤러 추가
AI/WJ/                               ← 여기에 모델 코드 추가
```

## 절대 수정 금지 파일 (공통 파일)

아래 파일은 팀 전체가 공유합니다. **본인 이니셜 폴더 외의 파일은 수정하지 마세요.**

### Frontend
| 파일 | 이유 |
|------|------|
| `frontend/src/App.jsx` | 라우팅 전체 설정 (이미 완성됨) |
| `frontend/src/components/*` | 공통 레이아웃 (Header, Sidebar 등) |
| `frontend/src/pages/LoginPage.jsx` | 공통 로그인 페이지 |
| `frontend/src/pages/MainPage.jsx` | 공통 대시보드 |
| `frontend/src/pages/PatientDetailPage.jsx` | 공통 환자 상세 |
| `frontend/src/index.css` | 공통 스타일 |
| `frontend/package.json` | 의존성 (추가 필요 시 팀장과 협의) |

### Backend
| 파일 | 이유 |
|------|------|
| `backend-main/src/.../SecurityConfig.java` | JWT 인증 전체 설정 |
| `backend-main/src/.../auth/*` | 로그인/회원가입 |
| `backend-main/src/.../user/*` | 사용자 관리 |
| `backend-main/src/.../patient/*` | 환자 관리 |
| `backend-main/src/.../worker/*` | AI 서버 헬스체크 |
| `backend-main/src/.../diagnosis/*` | 공통 진단 결과 저장 |
| `backend-main/build.gradle` | 의존성 (추가 필요 시 팀장과 협의) |
| `backend-main/src/main/resources/application*.properties` | 서버 설정 |

### AI
| 파일 | 이유 |
|------|------|
| `AI/main.py` | FastAPI 공통 라우터 |
| `AI/rag_engine.py` | RAG 엔진 (임베딩 + LLM) |
| `AI/requirements.txt` | 의존성 (추가 필요 시 팀장과 협의) |

### DB
| 파일 | 이유 |
|------|------|
| `backend-main/src/main/resources/db/migration/V1~V4__*.sql` | 공통 테이블 (완성됨) |

## 프론트엔드 개발 방법

### 내 페이지 파일 위치
```
frontend/src/[이니셜]/[모듈명]Page.jsx
```

예) WJ → `frontend/src/WJ/BrainTumorPage.jsx`

### App.jsx는 이미 완성되어 있습니다
각자 페이지 파일이 자동으로 라우트에 연결됩니다.
**App.jsx를 수정할 필요 없습니다.**

### 백엔드 API 호출 방법
진단 결과를 저장할 때 공통 API를 사용합니다:

```javascript
// 진단 결과 저장
POST /api/patients/{patientUid}/diagnoses
{
  "diseaseType": "brain-tumor",   // 본인 diseaseType
  "result": "...",                 // AI 진단 결과
  "confidence": 0.95
}

// 진단 기록 조회
GET /api/patients/{patientUid}/diagnoses
```

## 백엔드 개발 방법

### 내 패키지 위치
```
backend-main/src/main/java/com/example/backend_main/[이니셜]/
```

예) WJ → `com.example.backend_main.WJ` 패키지에 컨트롤러 생성

### 공통 진단 API 활용
`diagnosis` 패키지의 `DiagnosisController`가 진단 결과 저장/조회를 이미 처리합니다.
모듈별 추가 로직이 필요한 경우에만 본인 패키지에 새 컨트롤러를 만드세요.

### DB 테이블 추가가 필요한 경우
본인 DB 버전 번호로 마이그레이션 파일을 만드세요 (아래 DB 규칙 참고).

## AI 서버 개발 방법

### 내 폴더 위치
```
AI/[이니셜]/
```

예) WJ → `AI/WJ/` 폴더에 모델 코드 작성

### AI 서버 구조
```
AI/
├── main.py          ← 수정 금지 (공통 라우터)
├── rag_engine.py    ← 수정 금지 (RAG 엔진)
└── WJ/
    ├── model.py     ← 내 AI 모델 코드
    ├── schemas.py   ← 요청/응답 스키마
    └── router.py    ← 내 API 엔드포인트
```

### 내 엔드포인트 등록 방법
`AI/main.py`에 본인 라우터를 추가해야 합니다. 이 파일은 공통이므로
**PR 생성 후 팀장이 머지**하는 방식으로 진행하세요.

## DB 마이그레이션 규칙

### 버전 번호 배정 (절대 겹치면 안 됨)

| 버전 | 담당자 |
|------|--------|
| V1 ~ V4 | 공통 (완성됨, 수정 금지) |
| V5 | DH (김담현) |
| V6 | GW (박기완) |
| V7 | MS (김민수) |
| V8 | NJ (김남준) |
| V9 | SH (홍승현) |
| V10 | WJ (변운조) |

### 파일 생성 방법
```
backend-main/src/main/resources/db/migration/V[번호]__create_[테이블명].sql
```

예) WJ가 뇌종양 결과 테이블 만들기:
```sql
-- V10__create_brain_results.sql
CREATE TABLE brain_results (
    id          BIGSERIAL PRIMARY KEY,
    patient_uid VARCHAR(36) NOT NULL,
    tumor_type  VARCHAR(50),
    confidence  FLOAT,
    created_at  TIMESTAMP DEFAULT NOW()
);
```

> 한 번 실행된 마이그레이션은 수정 불가. 신중하게 작성하세요.

## Vector DB (pgvector) 규칙

자세한 내용은 `vectorGuide.md` 참고.

### 핵심 규칙 2가지

**1. 삽입 시: 반드시 본인 module 값으로 태깅**
```python
INSERT INTO medical_knowledge (module, content, embedding)
VALUES ('brain', '뇌종양 관련 의학 내용...', [...])
#       ^^^^^^ 본인 module명으로 고정
```

**2. 조회 시: 반드시 module 필터 포함**
```python
SELECT content FROM medical_knowledge
WHERE module = 'brain'   -- 이 줄 없으면 전체 데이터 검색 → 환각 발생
ORDER BY embedding <=> query_embedding
LIMIT 5
```

### module 이름 (반드시 이 값으로 통일)
| 담당 | module 값 |
|------|-----------|
| WJ (뇌종양) | `brain` |
| DH (허리디스크) | `spine` |
| GW (대장암) | `colon` |
| MS (피부질환) | `skin` |
| NJ (신부전) | `kidney` |
| SH (안과) | `eyes` |

## AI 도구(Claude Code / Cursor / Gemini) 사용 시

AI 도구에게 코드 작성을 요청할 때 아래 내용을 함께 전달하세요:

```
나는 MediCore 프로젝트의 [이름]입니다.
담당 모듈: [질환명] (module명: [module값])

작업 범위:
- Frontend: frontend/src/[이니셜]/ 폴더만
- Backend: com.example.backend_main.[이니셜] 패키지만
- AI: AI/[이니셜]/ 폴더만

절대 수정하지 말아야 할 파일:
- frontend/src/App.jsx
- frontend/src/components/*
- AI/main.py
- AI/rag_engine.py
- backend-main/src/.../SecurityConfig.java
- backend-main/src/.../auth/*, user/*, patient/*, worker/*
- db/migration/V1~V4 파일들

DB 마이그레이션이 필요하면 V[내번호]__파일명.sql 로 생성.
Vector DB 삽입/조회 시 WHERE module = '[내module명]' 필수.
```

## 시연 전 DB 합치기

각자 로컬 DB를 덤프해서 하나로 합칩니다.

```cmd
# 각자 본인 테이블 덤프
pg_dump -U medicore -d medicoredb -t [본인테이블명] > [이니셜]_dump.sql

# 시연 DB에 순서대로 import
psql -U medicore -d medicoredb < DH_dump.sql
psql -U medicore -d medicoredb < GW_dump.sql
...
```

공통 테이블(V1~V4)은 중복 없이 하나만 실행하면 됩니다.
